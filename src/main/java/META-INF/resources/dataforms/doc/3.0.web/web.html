3.0.WebComponentクラス階層

この章ではdataformsのWebアプリケーションの仕組みを解説します。

WebComponentクラスはWebページを構成する要素である、Page,Form,Field等の基底クラスです。 WebComponentから派生したクラスはそれと同じ名前を持つJavascriptのクラスが存在し、 ブラウザ上で動作するJavascriptのクラスと、サーバー上で動作するJavaのクラスが連携して動作します。

DafaFormsクラス階層

DafaFormsクラスはWebComponentクラスから派生し複数のFormの動作を取りまとめるためのクラスです。 このクラスでWebページの一般的な動作である1.検索条件を入力、2.結果リストの表示、3.選択したデータの編集の流れを実装しています。 PageクラスとDialogクラスはDataFormsクラスから派生しており、複数のFormを制御することができます。

Formクラス階層

FormクラスはWebComponentから派生した役割を定めていない汎用的なフォームのクラスです。 このクラスのサブクラスとして以下のクラスを用意しています。

フォームクラス
No. クラス名 機能
1 QueryForm DBの検索条件を入力し、検索を実行するフォームです。
2 QueryResultForm QueryFormに入力された検索条件を元にリストを表示します。 リストはページをスクロールする機能を持ちます。 リスト中の要素を選択することができます。
3 EditForm DB中のレコードを編集するフォームです。

Fieldクラス階層

FieldクラスはWebComponentから派生し、画面上の入力項目や表示項目（タグ）を制御するためのクラスです。 サーバーサイドのJavaでデータ型やバリデーション（入力チェック）を定義すると、対応するJavaScriptのFieldクラスへと自動的に引き継がれ、 ブラウザ側での動的な制御やエラー表示がシームレスに行われます。 主に用途やSQLのデータ型に応じて、以下の主要なサブクラスが用意されています。

フィールドクラス
No. クラス名 機能
1 TextField 通常のテキスト入力を制御する、最も基本的なフィールドクラスです。 このクラスのサブクラスにはDBのデータ型に対応した以下のクラスが用意されています。 VarcharField(varchar), CharField(char), ClobField(clob)
2 NumberField 数値入力を制御します。ブラウザ側での数値バリデーションなどと連動します。 このクラスのサブクラスにはDBのデータ型に対応した以下のクラスが用意されています。 SmallIntField(Short), IntegerField(Integer), BitIntField(Long), DoubleField(Double), NumericField(BigDecimal)
3 DateTimeField / DateField / TimeField 日付や時刻の入力を制御します。
4 SingleSelectField / MultiSelectField プルダウン（SelectField）やラジオボタン、チェックボックス等の「選択肢」を伴う入力を制御します。
5 UploadField ファイルのアップロードやダウンロード、画像（ImageField）や動画・音声のストリーミングといったバイナリデータの管理を制御します。

HtmlTableクラス階層

HtmlTableクラスはWebComponentから派生し、HTMLの<table>タグをオブジェクトとして制御するためのクラスです。 Java側で定義したテーブルの列構造と、HTML内のセルのID（フィールド名）が自動的にマッピングされます。 これにより、データベースから取得した複数件のレコードを一括で画面に描画したり、行単位でのデータ操作が容易になります。 主に用途に応じて以下のサブクラスが用意されています。

Htmlテーブルクラス
No. クラス名 機能
1 HtmlTable 主にデータの「閲覧・一覧表示」を行うための基本的なテーブルクラスです。
2 PageScrollHtmlTable 表示件数の多いデータに対して、自動的にスクロール（ページング）機能を付与するテーブルクラスです。QueryResultFormで利用しています。
3 EditableHtmlTable テーブルの行内で直接データの追加・変更・削除を可能にする、グリッド編集（行編集）用のテーブルクラスです。

DataFormsServletの動作

DataFormsServletはHogePage.htmlへのリクエストを受信すると、HogePage.classを検索します。 HogePage.classが存在すると、HogePage内に配置されたForm,Field,テーブルなどの情報をもとに 適切なJavascriptをHogePage.htmlに追加して送信します。 そのJavascriptはHogePage.html中の各要素に適切なイベント処理を設定し動作します。

PageクラスにはFormとDialogを配置することができます。 FormにはフィールドとHtmlTableを配置することができます。 Dialogにはフォームを配置することができます。
